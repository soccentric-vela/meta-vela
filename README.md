# meta-vela

Yocto layer for **Vela** (Qualcomm Snapdragon), part of the open-source Vela platform from [SoCcentric](https://soccentric.com).

It is used by [Vela-OS](https://github.com/soccentric-vela/Vela-OS), which holds the kas configuration that builds a full image.
